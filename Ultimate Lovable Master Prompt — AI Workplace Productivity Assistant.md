# MASTER BUILD PROMPT
## AI WORKPLACE PRODUCTIVITY ASSISTANT

Build a complete, functional, polished, modern web application called:

# **AI Workplace Productivity Assistant**

This application is an AI-powered workplace productivity platform designed to help users automate common professional tasks, improve productivity, understand information faster, and interact with an intelligent workplace assistant.

This is an academic/project application, but it must look and behave like a **real modern SaaS AI product**, not like a basic student prototype.

The application must directly demonstrate these five learning outcomes:

1. **Introduction to AI**
2. **Maximize Productivity with AI Tools**
3. **Discover the Art of Prompting**
4. **Use AI Responsibly**
5. **Stay Ahead of the AI Curve**

The final product must include all five required AI features:

1. Smart Email Generator
2. Meeting Notes Summarizer
3. AI Task Planner / Scheduler
4. AI Research Assistant
5. AI Workplace Chatbot

Do not build these as separate disconnected pages. Make them feel like parts of one integrated AI workplace ecosystem.

---

# 1. PRIMARY PRODUCT GOAL

The application should help a workplace user go from:

**Information → AI Processing → Useful Output → Action**

For example:

**Meeting Notes**
→ AI Summary
→ Decisions
→ Action Items
→ Tasks
→ Schedule

Or:

**Research Topic**
→ AI Research
→ Key Insights
→ Simplified Explanation
→ Professional Email

The application should therefore demonstrate that AI can be used not only for generating text, but also for **workflow automation, decision support, organization, summarization, planning, and productivity improvement**.

### OBJECTIVE

### CONTEXT

Information supplied by the user.

### AUDIENCE

Who will consume the result.

### CONSTRAINTS

Rules and limitations.

### OUTPUT FORMAT

### QUALITY CRITERIA

What makes the response good.

### ACCURACY RULES

### RESPONSIBLE AI RULES

Use structured/schema-based outputs for features where reliable parsing is important.

- Prompt construction
- API requests
- Responses
- Structured outputs
- Loading
- Errors
- Retry
- Regeneration
